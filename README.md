# Nawsites - Premium Web Development Website

A professional, responsive website for Nawar, a freelance web developer based in Dubai. Built with modern web technologies and advanced animations.

## 🚀 Features

- **Modern Development Setup**: Vite-powered development server with `npm run dev`
- **Fully Responsive**: Mobile-first design with hamburger menu
- **Advanced Animations**: Smooth scroll animations, floating effects, hover interactions
- **Modal Forms**: Professional quote request modal with validation
- **Interactive Elements**: Active navigation states, notification system, micro-interactions
- **Professional Design**: Navy blue and white corporate theme
- **Font Awesome Icons**: Beautiful icons throughout the interface
- **Form Validation**: Client-side validation with user feedback

## 🛠️ Tech Stack

- **HTML5**: Semantic markup
- **CSS3**: Advanced animations, Grid, Flexbox, Custom properties
- **Vanilla JavaScript**: ES6+ features, DOM manipulation
- **Vite**: Fast development server and build tool
- **Font Awesome**: Icon library
- **Google Fonts**: Inter typography

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Opens at `http://localhost:3000`

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
